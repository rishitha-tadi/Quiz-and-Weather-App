# 🌦️🧠 Quiz and Weather App

## 📌 Project Overview

The Quiz and Weather App is a simple and interactive web application that combines two useful features in a single project — a Quiz App and a Weather App.

The Quiz section tests users on basic web development knowledge, while the Weather section provides real-time weather information using the OpenWeatherMap API. The project was built to improve frontend development skills and gain hands-on experience with API integration using JavaScript.

---

# 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- OpenWeatherMap API  

---

# ✨ Features

## 🧠 Quiz App Features

- Multiple-choice quiz questions  
- Score calculation system  
- Interactive question navigation  
- Instant result display  
- Clean and responsive UI  

---

## 🌦️ Weather App Features

- Real-time weather updates  
- Search weather by city name  
- Displays temperature, humidity, and weather conditions  
- Weather icons and descriptions  
- API integration using OpenWeatherMap
